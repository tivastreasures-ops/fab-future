# Share-card artwork

Place these files in this folder (`public/card-art/`). They are loaded at
`${BASE_URL}card-art/<file>` and are never generated by the app.

| File | Used by | Content |
| --- | --- | --- |
| `lipstick-bullet.png` | Luxe | White, softly shaded lipstick bullet. Tinted by multiplying the chosen hex, so shading must be grayscale and the background transparent. |
| `lipstick-case-ornate.png` | Luxe (preferred) | Ornate plum/gold case with an EMPTY opening (transparent where the bullet shows). |
| `lipstick-case-simple.png` | Luxe (used only if ornate is missing) | Simpler case with the cat logo, empty opening. |
| `kiss-mark.png` | Kiss Mark | White textured kiss mark on transparent background. Only alpha is used: the shade fills it, texture and edges come from transparency. |

## Requirements

- PNG with real transparency. Replace files in place with the same names.
- Kiss: full alpha is used as a mask (soft edges and texture preserved), RGB is ignored.

## Alignment (profiled from the supplied files)

The files differ in size, so alignment is defined per file in `src/lib/card-art.ts`:

| File | Size | Opening center x | Opening rim y | Opening width |
| --- | --- | --- | --- | --- |
| `lipstick-case-ornate.png` | 1148 x 1370 | 0.724 | 0.175 | 0.235 |
| `lipstick-case-simple.png` | 1199 x 1312 | 0.61 | 0.29 | 0.225 |

Values are fractions of the case image. The bullet (`lipstick-bullet.png`,
1024 x 1536) is cropped at draw time to its opaque box 568 x 1188 at (224, 178),
scaled to 0.9 of the opening width, and drawn BEHIND the case with its base 5%
below the rim so the dark opening hides it while the tinted body rises above.
The renderer adds headroom above the case so the bullet stays inside the hero area.

If you replace an artwork with different dimensions or framing, update
`CASE_PROFILES` / `BULLET_SOURCE` accordingly (a bullet of a different size is
drawn uncropped).

If a file is missing or loads slowly (6 second limit), the card shows a plain
shade swatch captioned "Artwork not uploaded - shade swatch shown", and the
export dialog names the missing file outside the image.
